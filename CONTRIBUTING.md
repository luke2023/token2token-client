# Contributing

Thank you for helping build Token2Token Client.

Before implementation begins, proposals that change public wire behavior should
first update `token2token-provider-spec`. Client changes should remain
cross-platform where practical, keep connector privileges minimal, and avoid
persisting inference content.

Contributions should include focused tests, documentation for user-visible
behavior, and a clear statement of supported operating systems and engine
versions. By contributing, you agree that your contribution is licensed under
Apache-2.0.
