# Provider Guide

The provider workflow will be:

1. Install and enroll Token2Token Client.
2. Connect a supported local engine or enable an available managed runtime.
3. Discover models and complete missing license, capability, and pricing metadata.
4. Pass automatic conformance and streaming smoke tests.
5. Publish eligible endpoints and receive routed work.
6. Earn 95% of verified generation charges as Indigo.

New verified physical GPUs receive 500 Indigo credits subject to
account, device, and anti-abuse limits.
